# Descargas Nobilis

Instaladores oficiales de los plugins Nobilis. Bajalos desde la sección Releases o desde https://nobilis-sounds.netlify.app

## ACIES

Ecualizador dinámico. Instaladores en la carpeta [`acies/`](acies/), una subcarpeta por versión:

- Windows: `acies/v1.0.0/ACIES-Setup-Windows.exe`
- macOS (Apple Silicon e Intel): `acies/v1.0.0/ACIES-macOS.pkg`

Se descargan también desde Mi cuenta en https://nobilis.ar/cuenta/#descargas
